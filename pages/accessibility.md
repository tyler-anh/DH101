# Accessibility

This site was built by **Le Anh Tu** for DH 101. 
 
I have tried to make it accessible by:

- adding concise, meaningful alternative text to informative images across Weeks 1–8;
- checking foreground and background color combinations with the WebAIM Contrast Checker and adjusting combinations that did not meet the intended contrast requirements;
- using descriptive link text so visitors can understand the purpose of a link without relying on surrounding text;
- providing text descriptions or summaries for complex visual material, including maps, diagrams, and network visualizations;
- reviewing pages with the WAVE Accessibility Evaluator and correcting the issues I could identify;
- checking that the site can be navigated using a keyboard and that keyboard focus remains visible.

I recognize that accessibility is an ongoing process and that automated checkers cannot identify every barrier. If you encounter a problem using this site, please contact me at **le_a7@denison.edu** and include the page URL and a brief description of the barrier. I will use your feedback to improve the site.
